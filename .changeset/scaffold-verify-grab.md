Add `s2s grab`, `s2s scaffold` and `s2s verify` (Stage 5). `grab <url>` runs every stage in order and resumes after an interruption, then checks the untouched project and prints the command that hands it to Claude Code. Run `s2s` with no arguments for a guided prompt. `scaffold` writes a Vite project (React, Vue, Preact or vanilla; `--target` to choose) that builds and behaves like the site before any change. It also writes `AGENTS.md`, `PROMPT.md`, `PROGRESS.md`, a `/s2s` slash command, a narrow Claude Code allowlist, and a git repo with a first commit. `verify` builds the project and serves it with captured responses replayed, without contacting the site. It compares each page and viewport with the capture on pixels (regions that changed during capture are masked), DOM similarity, new console errors and failed requests. It writes `verify/report.md` for the agent and exits 0 on a pass, 1 on a regression, 2 when the build fails and 3 when verify cannot run. Capture now takes a second screenshot per page (`--mask-delay`) and records console errors. Stage 4 no longer turns non-React `createElement` calls into JSX, and a `react-dom` vendor import now includes `react-dom/client`.
