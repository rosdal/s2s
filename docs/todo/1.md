# s2s — Todo 1: Repo bootstrap

Nov 2, 2026 · @Mark

## Goal

This todo takes the empty `s2s` folder to a public, CI-green repo at `github.com/Rosdal/s2s`. Every package is an empty stub, and the npm name is reserved. No product code is written yet; that starts in Todo 2 (Stage 1: Capture). Reference: the [product design doc](https://claude.ai/artifact/LZeJQttSRxAbwfueZBYe4C).

**Done when**

- `Rosdal/s2s` is public, with a README that states what s2s is and its intended-use and legal stance
- `pnpm install && pnpm build && pnpm test && pnpm lint` passes locally and in GitHub Actions on an empty skeleton
- `pnpm exec s2s --version` prints `0.0.0` (the only logic allowed in this todo; any other input exits 1 with "not implemented"). Amended during execution: the original `pnpm --filter cli exec s2s --version` matches no package and exits 0 without running anything.
- `main` is protected: changes land through PRs with CI required
- The `@rosdal` npm scope is owned by you, so the package name can't be taken (deferred on Nov 2, 2026: npm org, token and name-holding publish wait until the package is ready)

## Decisions to lock first

Settle these before running `git init`, because each one is baked into file names, `package.json` fields or the license header. The one surprise is that **`s2s` is already taken on npm** (v0.20.1, last published June 2022), so the CLI should ship as `@rosdal/s2s` and keep `s2s` as its command name. The `@rosdal` scope doesn't exist on npm yet, so you can claim it.

| Decision          | Recommendation                                                                                    | Alternatives                                     |
| ----------------- | ------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| GitHub repo       | `Rosdal/s2s`, public                                                                              | `Rosdal/site-to-source`                          |
| npm package       | `@rosdal/s2s`, bin `s2s` (run as `npx @rosdal/s2s`)                                               | `site2source` (free, unscoped)                   |
| Internal packages | `@rosdal/s2s-core`, `@rosdal/s2s-ui`, `@rosdal/s2s-fingerprints`; only the CLI is public at first | Keep all `private: true` until v0.1              |
| License           | MIT                                                                                               | Apache-2.0 (adds an explicit patent grant)       |
| Node              | `engines: >=22`, develop on 24 LTS, `.nvmrc` = 24                                                 | Also test on Bun for running                     |
| Package manager   | pnpm (workspaces), pinned via `packageManager` + Corepack                                         | —                                                |
| Module format     | ESM only, TypeScript `strict`, `module: NodeNext`                                                 | Dual ESM/CJS (not worth it for a CLI)            |
| Build             | tsup per package                                                                                  | tsdown                                           |
| Lint + format     | Biome (one tool, fast)                                                                            | ESLint + Prettier                                |
| Tests             | Vitest                                                                                            | node:test                                        |
| Releases          | Changesets, publish from GitHub Actions with npm provenance                                       | release-please                                   |
| Commit style      | Conventional Commits                                                                              | Free-form, since Changesets writes the changelog |

Open question: is `s2s` the name you want public, or is this the moment to pick a real product name? Renaming after the npm and GitHub publish is possible but messy.

## Checklist

Work top to bottom. Nothing is pushed until group 6, so the public repo's first commit is already complete and green.
