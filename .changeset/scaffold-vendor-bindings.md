The scaffold names more bindings of inlined libraries instead of leaving them as the library's whole namespace. A chunk's import of another chunk's library binding follows that chunk's aliases (`gsap = core.registerPlugin(css) || core`). A copied instance of a minified library class (`new Xn()`) imports the class by shape (three's `Ray`). When bindings still stay unnamed, packages Stage 3 left in review are installed and tried; one that names a binding is added to the project and listed under its packages (Lenis on artefakt.mov), and the rest are removed again.
