Add `s2s unbundle` (Stage 4). It splits the site's first-party JS into one readable module per file under `recovered/unbundled/<chunk>/`: webpack 4 and 5 on their real module maps (merged across chunks), Browserify on its module table, esbuild and Rolldown on their CommonJS/ESM wrappers, and Vite/Rollup chunks on partial source-map boundaries or, failing that, clusters of the reference graph. Code inside Stage 3's vendor ranges is replaced with package imports. Each module then goes through deobfuscation (webcrack, with obfuscator code run in a locked-down child process), unminify, de-transpile (classes, async/await, spread, optional chaining and more, including Babel helpers a minifier inlined), JSX restore, CommonJS-to-ESM and Prettier; `--skip <pass>` turns any of them off. First-party CSS is formatted into `styles/`, CSS Module class maps become `import styles from "./X.module.css"` with local class names restored, and images, fonts and media are copied into `assets/` with their references rewritten. It writes `analysis/modules.json` (module graph, kind guesses, work order and agent groups), `bundler.json`, `styling.json` and `unbundle-report.json`, and adds the bundler to `project/package.json`. Output is deterministic; `--keep-vendor`, `--no-heuristic-split` and `--max-group-kb` tune it.
